# Caja Ternok para Windows

El instalador del programa de la caja de Ternok: abre la caja en su propia ventana e imprime el ticket directo en la impresora predeterminada, sin la ventana de imprimir.

**Bajar:** [CajaTernok-instalador.exe](https://github.com/frannkurt/caja-ternok/releases/latest/download/CajaTernok-instalador.exe)

1. Conectar la impresora de tickets y dejarla como predeterminada en Windows.
2. Abrir el instalador. Si Windows avisa «Windows protegió su PC», tocar «Más información» y «Ejecutar de todas formas».
3. Se abre la caja: entrar con el usuario de siempre. Queda el ícono «Caja Ternok» en el escritorio.

Este repositorio tiene solo el instalador. El programa y el sistema son de Ternok.
